Privacy Policy

Some Else Where — last updated 4 October 2026

"Some Else Where" is a personal automation tool used by a single individual to publish videos to their own YouTube channel. It is not offered to the public, has no sign-up, and has no users other than its owner.

Information it accesses

When its owner authorises it, the tool uses Google APIs to act on that owner's own YouTube channel, under these scopes:

  • youtube — to upload videos to the owner's channel and set their titles, descriptions, and visibility.
  • yt-analytics.readonly — to read view and retention statistics for that same channel, so the tool can measure how its own videos performed.

It accesses no other Google data: no Gmail, no Drive, no contacts, no profile information beyond what is required to identify the channel being published to.

How information is used

Solely to publish the owner's videos and to report on those videos' performance back to the owner. Analytics data is used to adjust what the tool produces next.

Storage

The OAuth token is stored in a single file on the owner's own computer. Nothing is transmitted to, or stored on, any server operated by this project — there is no server. Analytics data is read on demand and is not retained beyond the owner's local machine.

Sharing

No data is sold, shared, transferred, or disclosed to any third party. There is no advertising, no analytics SDK, and no tracking of any kind.

Limited Use

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke this application's access at any time at myaccount.google.com/permissions, which immediately invalidates its credentials.

Children

The tool is not directed at children and collects no information from anyone, including children.

Changes

Any change to this policy will be published on this page with an updated date above.
